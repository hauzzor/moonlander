## Original request

Rebuild Moonlander game code from `docs/spec.md`. The existing game is preserved
on `backup/pre-rebuild`. The pre-rebuild baseline was green: 136 unit tests, 21
Playwright tests, typecheck, and production build.

## Goal

Freeze the target contract for the rebuild so every later ticket implements the
same public API, constants, observation semantics, and empirical targets.

## Current behavior

- T-0001 froze near-vertical tunnel constants and a no-behavior `halfWidthAt`
  stub. The generator, observation, autopilot, and renderer still use the old
  gentle, constant-width behavior.
- `docs/spec.md` contains the new tunnel and observation contract but still
  states the old autopilot benchmark of 400 m per seed, median 500 m, and 8 m/s.
- The confirmed near-vertical brief uses 200 m per seed, median 300 m, and
  4 m/s average world-x speed.

## Desired behavior

- `docs/spec.md` is the source of truth. Update the autopilot benchmark to the
  confirmed near-vertical values and remove the T-0001 staging language.
- Freeze public types, constants, and exports for the rebuild in
  `packages/sim/src/types.ts`, `constants.ts`, and `index.ts`.
- Keep compiling stubs with no new behavior where implementation belongs to a
  later ticket.
- Update target tests so they express the rebuilt behavior, not the old gentle
  tunnel or old benchmark.

## Non-goals

- Implementing field generation, physics, collision, sensors, or autopilot.
- Game rendering or UI changes.
- Changing controls, score rules, damage rules, or delivery policy.

## Contract freeze

- Public types: `Vec2`, `Action`, `ShipState`, `EyeSensorReading`,
  `DirectionSensorReading`, `VelocitySensorReading`, `SensorSuite`, `SimState`,
  `ShipStart`, `SimulationOptions`, `CurvedWall`, `Tunnel`, `FieldChunk`,
  `Field`, `Observation`, `Controller`, `Simulation`.
- Constants: all required exports in `docs/spec.md`, including the tunnel
  bounds, ship values, drag, damage, eye sensor, rear thruster, and seed
  constants.
- `Tunnel.halfWidthAt(x)` is the local perpendicular half-width.
  `Tunnel.halfWidth` remains the nominal 34 m.
- `Observation.tunnelHalfWidth` is local; `tunnelCenterOffset` is the signed
  perpendicular offset.
- Typecheck: `npm.cmd run typecheck`.

## Acceptance criteria

1. `docs/spec.md` states the 200/300/4 autopilot benchmark and the full
   near-vertical/variable-width contract.
2. Public types, constants, and exports match the spec.
3. Typecheck passes after the contract update.
4. Contract-level tests compile and pass; behavior target tests are owned by
   the implementation tickets and must not leave `verify` red.
5. No game behavior is implemented in this ticket.

Sequencing note: the full 8-seed autopilot benchmark is deferred to T-0008,
which owns the autopilot retune and `packages/sim/test/autopilot.test.ts`. The
near-vertical, variable-width, and adaptive-sampling field tests are deferred to
T-0004. Both are relocations to the owning implementation tickets, not waivers;
the benchmark and behavior tests must exist before the rebuild closes.

## Edge cases

- Negative x and the straight start.
- Near-vertical slope and variable width boundaries.
- Local versus nominal half-width.
- Perpendicular versus vertical center offset.
- Benchmark seed set and median calculation.

## Original request

Add a game-loop simulation speed control from 0.1x to 10x and a collapsible SIM
panel with four log sliders: speed, gravity, bottom thruster power, and rear
thruster power. Persist all four across R/seed and reloads via URL/localStorage.

## Goal

Expose the simulation scales from T-0020 and a wall-clock time scale in a
responsive SIM panel without changing per-tick physics or the default benchmark.

## Current behavior

No SIM panel; speed is real-time; gravity/power are constant; only the seed is
URL-controlled and settings do not survive reload.

## Desired behavior

- `GameOptions.timeScale`, `Game.setTimeScale`, `Game.getTimeScale`; clamp
  0.1-10, default 1.
- `advance` multiplies wall elapsed by time scale before the fixed accumulator.
- Dynamic per-frame cap `ceil(MAX_STEPS_PER_FRAME * timeScale)` with hard ceiling
  1200; camera uses scaled delta.
- Four log sliders in a collapsible SIM panel: speed, gravity, bottom power, rear
  power; 0.1x-10x, 1x centered, step 0.05 in log10 space.
- Readouts: `x`, effective m/s² for gravity, numeric `data-value`.
- Panel always visible in manual and autopilot, outside the sensor console;
  toggle with `aria-expanded`/`data-collapsed`.
- Persistence: R/seed + URL + localStorage; precedence URL > localStorage >
  defaults; `?speed=`, `?gravity=`, `?bottomPower=`, `?rearPower=`; keys
  `moonlander.speed`, `moonlander.gravity`, `moonlander.bottomPower`,
  `moonlander.rearPower`; `history.replaceState` on change.
- SIM-panel sliders block Q/W/Space/E/R while focused; the sensor radius slider
  keeps its T-0018 pass-through behavior.
- `simulation-status` hook reports tick, time, time scale, gravity, and power
  scales.

## Non-goals

- No sim physics changes (T-0020 owns them).
- No sensor console visibility changes.
- No new keyboard shortcuts.
- No build/changelog changes.

## Acceptance criteria

1. Four sliders exist with ranges/defaults/step/log mapping/readouts.
2. 10x runs ten simulated seconds per real second at normal frame rates; 0.1x
   runs one tenth; fixed 120 Hz ticks unchanged.
3. Long frames at 10x within the existing `0.25 s` raw-frame clamp do not
   silently drop time.
4. Settings apply live, persist across R/seed, and load from URL/localStorage
   with documented precedence.
5. Panel is collapsible and causes no overflow at desktop/narrow widths.
6. SIM-panel focus blocks game keys; sensor radius slider keeps T-0018 behavior.
7. The default autopilot benchmark and existing sensor/build/changelog tests
   remain green.
8. `npm.cmd run verify`, local Playwright, and live suite pass.

## Edge cases

- Invalid URL/localStorage values; storage unavailable.
- 10x long frame; 0.1x few ticks.
- Collapsed panel on narrow viewport.
- R/seed with custom settings.
- Destroyed state and settings changes.
- Slider keyboard Home/End/arrows and focus.

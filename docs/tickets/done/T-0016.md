## Original request

Split from T-0007 so the game sensor console and radar can be rebuilt while the
simulation sensor module and integration are in progress.

## Goal

Render the last eye-sensor scan, direction needle, distance-to-start, velocity,
radius slider, and world-aligned radar overlay using the static hooks from
T-0015 and the sensor suite exposed by T-0013.

## Current behavior

The old sensor console and radar target the previous tunnel and renderer.
T-0015 provides the renderer and static hooks; T-0007 and T-0013 provide the
sensor data.

## Desired behavior

- Eye chart with 360 distances and a visible radius.
- Radius slider 20-200 with the configured value and next-scan behavior.
- Scan tick, direction needle with signed degrees, distance-to-start, and
  velocity blocks.
- World-aligned radar overlay showing the last scan and ship heading.
- Console updates only from simulation state and never mutates it.
- Use the static `data-testid` hooks owned by T-0015; do not edit `index.html`.
- Responsive console layout that does not cover the canvas on the normal
  desktop viewport.

## Non-goals

- Sensor math, simulation integration, or public API changes.
- Renderer orchestration, ship drawing, HUD, input, seed controls, or game
  wiring.
- Adding new sensors or changing the scan cadence.

## Acceptance criteria

1. The console renders the last scan, radius, tick, direction, distance, and
   velocity from simulation state.
2. The radius slider covers 20-200 and displays the configured value.
3. The radar overlay is world-aligned and uses the last scan.
4. The documented sensor hooks are stable and state-driven.
5. Rendering never mutates simulation state.
6. Typecheck and build pass; browser coverage passes in T-0010.

## Edge cases

- Radius at 20 and 200.
- Radius change pending before the next scan.
- Ship touching a wall or destroyed.
- Responsive console overlap.
- First-second data before the second scan.

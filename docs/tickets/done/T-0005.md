## Original request

Split from the original T-0005 so the pure physics module can be rebuilt in
parallel with collision and sensors, followed by T-0013 integration.

## Goal

Rebuild the deterministic rigid-body force, torque, and drag helpers from
`docs/spec.md` without changing the simulation trunk.

## Current behavior

`packages/sim/src/physics.ts` contains the old thruster and drag helpers. The
simulation still integrates the old behavior until T-0013.

## Desired behavior

- Mass 200 kg, length 48 m, height 18 m, inertia 43,800 kg·m².
- Left and right bottom thrusters at 1,800 N, 15 degree cant, mounts
  `{-16, -9}` and `{16, -9}`.
- Rear booster 900 N at `{-24, 0}` along local +x, no torque.
- Linear drag 0.35/s and angular drag 0.25/s, applied after thrust, gravity, and
  torque and before position integration.
- Q/W continuous while held; rear latch controlled by the game.
- Pure helpers return forces, torque, and drag factors; they do not advance
  position or own simulation state.
- Response targets are verified through T-0013, not by mutating the simulation
  from this ticket.

## Non-goals

- Collision, damage, sensors, autopilot, field generation, simulation
  integration, or UI.
- Changing ship constants or the public API.
- Integrating the helpers into `simulation.ts`.

## Decision log

| Decision | Choice | Rationale |
| --- | --- | --- |
| Model | Rigid-body force and torque helpers | Spec |
| Drag order | After forces, before integration | Spec |
| Rear booster | 900 N, no torque | Spec |
| Integration | Separate T-0013 | One writer on simulation.ts |

## Contract freeze

`Action`, `ShipState`, `SimState`, `SimulationOptions`, `Simulation`, and all
ship/drag constants follow T-0003.

The internal signatures consumed by T-0013 are frozen:
`rotate(vector: Vec2, angle: number): Vec2`,
`ThrusterEffect { force: Vec2; torque: number }`,
`thrusterEffect(angle: number, action: Action): ThrusterEffect`,
`linearDragFactor(dt: number): number`,
`angularDragFactor(dt: number): number`,
`applyLinearDrag(velocity: Vec2, dt: number): Vec2`, and
`applyAngularDrag(angularVelocity: number, dt: number): number`.

## Acceptance criteria

1. Ship constants and thrust geometry match the spec.
2. Q/W and rear thrust produce the specified forces and torques.
3. Drag helpers match the coefficients and apply in the specified order when
   integrated by T-0013.
4. The same inputs produce the same helper outputs.
5. Typecheck and focused tests pass.

## Edge cases

- Both bottom thrusters held together.
- Rear plus bottom thrusters.
- Release from 20 m/s.
- Free fall and terminal speed.
- Pure helper calls with no action.

## Affected interfaces

`packages/sim/src/physics.ts` and `packages/sim/test/physics.test.ts`.

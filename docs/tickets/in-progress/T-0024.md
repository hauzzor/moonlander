## Goal

Boot to a start menu with three freely selectable levels, deep-link `?level=`,
and an in-game pause menu with Resume/Restart/Return to Start.

## Requirements

- Start menu cards for `Inside the Sandworm's Gut`, `Gravity`, `Anti Gravity`;
  no locks; `?level=` auto-starts valid levels; invalid levels show the menu.
- Level start creates a new seed unless `?seed=` supplies one; writes `level`
  and `seed` to the URL while preserving SIM params.
- No simulation ticks while the start menu is open.
- In-game menu button pauses; release input/rear latch; freeze ticks; resume
  without catch-up; Restart reseeds current level; Return to Start abandons and
  shows the menu.
- Escape toggles the pause menu when the changelog modal is closed; game keys
  are ignored while either menu is open; focus returns to the menu button.
- Level name/HUD hook; `?level`/seed state.
- Do not implement top-thruster/control remap, heat map, or open-space
  renderer/planets behavior beyond what is needed to start a level.

## Test contract

Menu boot/free selection/deep links/invalid level; pause tick freeze/resume/
restart/return; URL/seed; key isolation/focus; no console errors; Level 1 starts
and remains playable.

## Verification

Game tests, local Playwright, typecheck/build; report risks.

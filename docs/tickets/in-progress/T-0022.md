## Goal

Freeze the level/world/planet/top-thruster public contract and create
compiling stubs before parallel implementation.

## Required contract

- `LevelId = "sandworm" | "gravity" | "anti-gravity"`.
- `Planet` with stable id, position, velocity, radius 24, surface gravity 8.0,
  polarity attract/repel.
- `World` union with `kind: "tunnel" | "space"`, seed, spawn, gravityAt,
  progressAt, planetsInView, wallsInView, stepBodies; tunnel world wraps the
  existing `Field`.
- `SimulationOptions.level?`, `topThrusterScale?`.
- `Action.top?` optional, normalized false; `SimState.thrusters.top` required.
- `SimState.level`, `planets`, `gravityAcceleration`, `topThrusterScale`.
- `Observation.level`, `planets`, `gravityAcceleration`, `topThrusterScale`;
  neutral tunnel fields in space levels.
- `Simulation.level`, `world`, `setTopThrusterScale`, existing setters.
- Constants for planet radius/surface gravity/range/cell/density/gap/spawn
  clearance/drift/restitution and top thruster force/mount.
- `createField(seed)` remains tunnel; `createSpaceField(level, seed)` stub.

## Rules

- Additive where possible; typecheck must pass with stubs.
- No behavior change to Level 1.
- Update `docs/spec.md`/`docs/autonomy.md` contract text.
- Test-engineer updates exact-shape fixtures in `packages/sim/test` and
  `packages/game/test` only as needed to compile.
- Do not implement gravity, planets, drift, menu, or top-thruster behavior.

## Verification

`npm.cmd run typecheck`; focused type/shape tests. Report contract decisions and
any needed follow-up.

## Parallelization plan

Serial contract wave. Each later ticket depends on this freeze. Test-engineer
migrates fixtures alongside the stub; no behavior.

## Original request

Verify the completed rebuild against `docs/spec.md` and report the result.

## Goal

Confirm the rebuilt game is playable, deterministic, tested, documented, and
live, then close the rebuild.

## Current behavior

The preceding rebuild tickets T-0003 through T-0011 and T-0013 through T-0017
are complete. This is the final gate.

## Desired behavior

- Full `npm.cmd run verify` is green.
- `npm.cmd run sim:demo` is deterministic and finite.
- The live Playwright suite passes against GitHub Pages.
- Every acceptance criterion in `docs/spec.md` is covered by code or a test.
- The rebuild report records the baseline, tickets, commits, test counts, live
  URL, and any residual risk.
- `backup/pre-rebuild` and history remain intact.
- No game code changes in this ticket. If a defect is found, create a new ticket
  and stop.

## Non-goals

- New features.
- Refactors without a confirmed defect.
- Deleting the backup branch.

## Acceptance criteria

1. `npm.cmd run verify` passes.
2. `npm.cmd run sim:demo` produces finite deterministic telemetry.
3. The live suite passes.
4. The rebuild report is written and linked.
5. No unresolved blocking review findings.
6. `backup/pre-rebuild` and history remain intact.

## Edge cases

- Pages propagation delay.
- Playwright flake on the live site.
- Spec references to superseded behavior.
- Backup branch or history missing.
- A late defect discovered during the final gate.

## Affected interfaces

Ticket status, rebuild report, documentation, and `AGENTS.md`.

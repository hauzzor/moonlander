## Original request

Rebuild the Playwright browser coverage for the integrated game.

## Goal

Prove the real page is playable and that every documented hook and behavior is
stable.

## Current behavior

The existing e2e suite targets the old game. The integrated shell is produced by
T-0009; pure game tests are owned by T-0015.

## Desired behavior

- Page loads without uncaught errors or console errors.
- Canvas is present, visible, and renders non-empty pixels.
- Q and W activate the correct thrusters; release deactivates.
- Space toggles the rear thruster and R resets it.
- E toggles MANUAL/AUTOPILOT; manual input is ignored while active.
- R starts a new seeded run and restores hull, score, and progress.
- Seed display, input, and load work with unsigned 32-bit seeds.
- Eye-sensor panel, chart, radius slider, scan tick, direction needle,
  distance-to-start, and velocity blocks show numeric values.
- Radar overlay is visible and updates with the last scan.
- Autopilot makes progress while active.
- Outcome overlay is attached but hidden while flying.
- Instructions mention Q, W, Space, E, and R and describe staying inside the
  tunnel.
- The documented `data-testid` hooks remain stable.
- Responsive layout does not cover the canvas or controls on the normal
  desktop viewport.

## Non-goals

- Changing game behavior, simulation code, or pure game tests.
- Visual regression screenshots beyond canvas non-emptiness.
- Testing the live deployment here; that belongs to T-0011/T-0017.

## Contract freeze

The `data-testid` hooks in `docs/spec.md` are frozen. The local Playwright server
uses the configured project port and must be serialized with delivery.

### Test contract

- Formulas and constants: every documented `data-testid` hook; Q/W/Space/E/R;
  seeds `0`, max unsigned 32-bit, invalid; radius 20/200; autopilot/manual
  ownership; no uncaught or console errors; responsive narrow/desktop layout.
- Expected values: controls change the documented HUD/state; seeds load and
  restart deterministically; sensor blocks show numeric values; outcome overlay
  hidden while flying; canvas renders non-empty pixels.
- Thresholds: local `npm.cmd run test:e2e` passes with stable timing;
  browser suites are serialized with delivery.
- Test files: `e2e/game.spec.ts`, `e2e/smoke.spec.ts`, and
  `playwright.config.ts`.
- Table-driven cases: seeds, control keys, sensor values, layout sizes.

## Acceptance criteria

1. The Playwright suite covers every documented page hook and control.
2. Tests fail on missing behavior, not flaky timing.
3. The page has no uncaught errors or console errors.
4. Autopilot and manual control behavior are both covered.
5. `npm.cmd run test:e2e` passes.

## Edge cases

- R during flight and after destruction.
- Seed input focus and Enter.
- Slider drag then next scan.
- Autopilot on with manual keys held.
- Narrow viewport.
- Canvas resize and DPR.

## Affected interfaces

`e2e` and `playwright.config.ts`.

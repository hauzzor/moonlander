## Original request

Split from the original T-0009 so the pure game modules and renderer can be
rebuilt in parallel, then wired into the playable game after the simulation,
autopilot, and sensor console are ready.

## Goal

Deliver the fixed-step game loop and wiring around the rebuilt simulation,
renderer, autopilot, seed controls, and sensor console.

## Current behavior

The old shell targets the previous game. The rebuilt pieces are produced by
T-0013, T-0014, T-0015, and T-0016.

## Desired behavior

- Bootstrap-only `main.ts`; wiring and the fixed-step loop in `game.ts`.
- Fixed timestep `1 / 120` with an accumulator.
- Q/W continuous thrusters, Space rear latch, E autopilot, R restart.
- Rear latch resets on R, blur, and page hide; autopilot owns all thrusters while
  active and manual input is ignored.
- Seed display, copy, input, load, and deterministic restart wired through
  `seed-controls.ts`.
- Destroyed overlay with the final score.
- All documented `data-testid` hooks driven by simulation state.
- Integrate the sensor console and radar from T-0016 through the renderer hook.
- Rendering reads state only and never mutates it.

## Non-goals

- Rebuilding the pure game modules, renderer, static hooks, or sensor console.
- Changing simulation behavior, sensor math, tunnel geometry, or the public API.
- New controls, touch input, audio, multiplayer, or leaderboards.
- E2E test authoring (T-0010).

## Acceptance criteria

1. The page is fully playable with Q, W, Space, E, and R.
2. The fixed-step loop, rear latch reset, autopilot ownership, seed controls,
   sensor console, and destroyed overlay are wired.
3. All documented `data-testid` hooks are present and state-driven.
4. Rendering never mutates simulation state.
5. Typecheck, focused tests, and build pass.

## Edge cases

- Seed input focus and Enter.
- R during flight and after destruction.
- Blur or page hide with the rear latch on.
- Manual input while autopilot is active.
- Resize before the first render.
- Narrow viewport console overlap.

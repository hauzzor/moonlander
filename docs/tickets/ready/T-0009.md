## Original request

Rebuild the browser game shell from `docs/spec.md`.

## Goal

Deliver a polished, responsive Canvas game around the rebuilt simulation with
stable controls, HUD, seed handling, and documented test hooks.

## Current behavior

The existing shell targets the old game. It must be rebuilt from the spec and
integrated with the rebuilt simulation, field renderer, and sensor console.

## Desired behavior

- Fixed-timestep loop with an accumulator.
- Bootstrap-only `main.ts`; wiring and loop in focused modules.
- Q/W continuous thrusters, Space rear latch, E autopilot, R restart.
- Rear latch resets on R, blur, and page hide; autopilot owns all thrusters
  while active.
- Smooth 2D follow camera with look-ahead and no rotation.
- HUD: hull, speed, progress, score, thruster states, autopilot status, seed.
- Seed display, copy, input, load, and deterministic restart.
- Instructions mention Q, W, Space, E, and R and describe staying inside the
  tunnel.
- Destroyed overlay with the final score.
- Responsive layout and device-pixel-ratio handling.
- All documented `data-testid` hooks present and driven by simulation state.
- Rendering reads state only and never mutates it.

## Non-goals

- Changing simulation behavior, sensor math, or tunnel geometry.
- New controls, touch input, audio, multiplayer, or leaderboards.
- Replacing the Canvas 2D renderer.

## Decision log

| Decision | Choice | Rationale |
| --- | --- | --- |
| Loop | Fixed-step accumulator | Spec |
| Controls | Q/W/Space/E/R | Existing product |
| Camera | 2D follow, no rotation | Spec |
| HUD | State-driven | Test hooks |
| Hooks | Preserve documented data-testid | Playwright contract |

## Acceptance criteria

1. The page is fully playable with Q, W, Space, E, and R.
2. Camera, HUD, seed controls, instructions, and destroyed overlay match the
   spec.
3. All documented `data-testid` hooks are present and state-driven.
4. The layout is responsive and the canvas handles DPR.
5. Rendering never mutates simulation state.
6. Typecheck, unit tests, and build pass.

## Edge cases

- Seed input focus and Enter.
- R during flight and after destruction.
- Blur or page hide with the rear latch on.
- Manual input while autopilot is active.
- Resize before the first render.
- Narrow viewport console overlap.

## Affected interfaces

Game modules, `index.html`, `style.css`, and pure game helper tests.

## Verification plan

1. Run focused game tests, typecheck, and build.
2. Run `npm.cmd run verify`.
3. Manually check a fixed seed in the browser.
4. Review and deliver.

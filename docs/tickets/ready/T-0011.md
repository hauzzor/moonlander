## Original request

Rebuild the delivery pipeline and reconcile the documentation with the rebuilt
game.

## Goal

Ensure every green `main` build deploys to GitHub Pages and that the live suite
proves the deployed game.

## Current behavior

The existing CI and delivery scripts work for the old game. The spec and
autonomy docs still contain T-0001 staging language and possibly the old
benchmark.

## Desired behavior

- CI runs typecheck, unit tests, `sim:demo`, local Playwright, and production
  build on push and pull request.
- `main` deploys the built `packages/game/dist` through GitHub Actions Pages.
- The live Playwright suite runs against the deployed URL after deployment.
- `npm.cmd run deliver` verifies, commits intended changes, pushes `main`,
  waits for the live asset, and runs the live suite.
- No force-push, amend, reset, or clean.
- `README.md`, `docs/spec.md`, and `docs/autonomy.md` describe the rebuilt game
  and current benchmark.
- Remove stale T-0001 staging language and old 400/500/8 benchmark references.

## Non-goals

- Changing game behavior.
- Adding new deployment providers or secrets.
- Rewriting the ticket tooling.

## Decision log

| Decision | Choice | Rationale |
| --- | --- | --- |
| Pages | GitHub Actions artifact flow | Existing CI |
| Live suite | Full Playwright against Pages | Spec |
| Delivery | Direct push after verify and review | User selected |
| Docs | Spec as source of truth | Rebuild contract |

## Contract freeze

The documented commands, hooks, and benchmark in `docs/spec.md` are frozen by
T-0003 and the preceding tickets.

| CI | — | Workflow runs verify and build | PR and main | release-engineer |

| Live suite | — | Live smoke against Pages | Asset wait and timeout | release-engineer |
| Docs | — | Commands and hooks accurate | Spec and autonomy consistency | release-engineer |

## Acceptance criteria

1. CI runs the full verification and `sim:demo`.
2. `main` deploys to GitHub Pages.
3. The live Playwright suite passes against the deployed URL.
4. Delivery never force-pushes and stops on failure.
5. Docs match the rebuilt game and benchmark.
6. `npm.cmd run verify` and `npm.cmd run test:e2e:live` pass.

## Edge cases

- Pages asset propagation delay.
- PR run without deployment.
- Live suite timeout.
- Docs references to removed behavior.
- Missing or stale npm scripts.

## Affected interfaces

CI workflow, delivery and live scripts, root package scripts, README, spec, and
autonomy docs.

## Verification plan

1. Run `npm.cmd run verify`.
2. Run `npm.cmd run sim:demo`.
3. Deliver to `main`.
4. Wait for Pages and run `npm.cmd run test:e2e:live`.
5. Review docs against the spec.

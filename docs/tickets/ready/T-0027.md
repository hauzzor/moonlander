## Goal

Make Level 3 "Anti Gravity": repulsive planet gravity, deterministic gentle
planet drift, mutual repulsion, and equal-mass planet collisions with
restitution 0.8 and no destruction.

## Requirements

- Planets start with seeded drift 0.2-1.0 m/s; damping 0.02/s; speed cap 2 m/s.
- Mutual repulsion is soft, not a hard separation rule; planets can collide.
- Planet-planet equal-mass circle collision, restitution 0.8, no destruction,
  deterministic fixed order; resolve overlap and exchange velocities.
- Ship gravity from planets is repulsive; no base gravity.
- Step planets once per fixed tick before ship gravity/collision; reset restores
  initial planet state; no drift from getters/rendering.
- Level 2 planets remain fixed; Level 1 unchanged.

## Test contract

Deterministic drift/reset; equal/opposite repulsion; speed cap; planet-planet
collision restitution; no destruction; repulsive ship acceleration; finite
values; long-run determinism; Level 2/1 regressions.

## Verification

Focused sim tests, typecheck, `sim:demo`; report risks.
